# Security Policy

PromptWatch test suites and answer files may contain private prompts, customer tickets, or model outputs. Do not include sensitive data in public issues or pull requests.

## Reporting Issues

If you find a security problem, please open a private advisory or contact the maintainers directly.

## Data Handling

The core CLI reads local files and prints local reports. It does not send prompts, answers, or citations to an external service.
