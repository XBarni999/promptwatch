# Code of Conduct

## Our Pledge

We want PromptWatch to be a welcoming open-source project for developers, testers, researchers, and product builders working with AI systems.

Contributors are expected to communicate respectfully, assume good intent, and keep discussions focused on improving the project.

## Unacceptable Behavior

Unacceptable behavior includes harassment, personal attacks, discriminatory language, threats, and repeated disruption of project discussions.

## Reporting

If you see behavior that makes the project unsafe or unwelcoming, please contact the maintainer or open a GitHub issue if appropriate.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or block users who violate this code of conduct.
