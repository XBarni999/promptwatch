# Roadmap

PromptWatch focuses on practical AI regression testing for teams that ship LLM features.

## 0.1

- Offline answer-file evaluation
- Deterministic text, regex, JSON, and citation checks
- JSON reports for CI systems

## 0.2

- Live adapter runner
- Snapshot diff reports
- HTML report output
- More examples for RAG, agents, and tool-calling apps

## 0.3

- Optional judge-model checks
- Production feedback importers
- Evaluation history summaries
- GitHub PR comment integration
